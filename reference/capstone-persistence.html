Seam

type RateLookup = String => IO[Option[Int]]

def quotesRoutes(config: QuotesConfig, lookup: RateLookup)
def quotesLookup(xa: Transactor[IO]): RateLookup
  • Core: convertAmount(code, qty, minQty, cents: Option[Int]). No JDBC.
  • rateOf stays Map.get — seed oracle, not the request path.
  • Memory lookup for fast tests. H2 migrate + seed for the program. One Postgres GET for the engine.

Outcomes

lookup(code).attempt.flatMap {
  case Left(_)            => ServiceUnavailable(ApiError("unavailable"))
  case Right(None)        => NotFound(ApiError("not_found"))
  case Right(Some(cents)) => Ok(RateOut(code, cents))
}
  • POST unknown code stays 422. GET miss stays 404.
  • OpenAPI is silent on 503. ADR 3. RFC 9110 fills it, as 405 did in scala-030.
  • Retry-After is optional. Not this unit.
