Option

Typed absence: one value, or none. Not a reason, not null.

Lesson: Option and safe absence. API (Scala 3.3.8): Option, Some, None.

Shape

ValueMeaning
Some(x)The container holds x.
NoneThe container is empty.
Option(x)None if x == null, otherwise Some(x).

Construct

Some("Ada")
None
users.find(_.id == id)          // already returns Option[User]
Option(javaMap.get(key))        // null-safe edge

Consume

opt match
  case Some(value) => value
  case None        => fallback

opt.map(f)                      // Option[B]; None stays None
opt.flatMap(f)                  // f returns Option[B]
opt.filter(p)                   // Some only if p holds
opt.getOrElse(fallback)         // unwrap or default
opt.foreach(println)            // runs only for Some

Combine

for
  user  <- findUser(users, id)
  email <- user.email
yield email
// None if the user is missing or the email is missing

Do not

  • Call .get — it throws on None.
  • Return null, a dummy record, or a magic 0 to mean “missing”.
  • Treat None as an error message. That is Either / Try.

Backend uses

  • Lookup by id: Option[User].
  • Optional field: email: Option[String].
  • Optional query parameter or missing JSON field.
