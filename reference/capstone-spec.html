Capstone architecture and API specification

OpenAPI is the HTTP contract. Layers name ownership. An ADR records one decision.

Lesson: Capstone architecture and API specification. Docs: OAS 3.1.2, Introduction, Structure, Endpoints, Nygard ADRs. This unit pins openapi: 3.1.2. No new Scala library.

OpenAPI

openapi: 3.1.2
info:
  title: quotes
  version: 0.1.0
paths:
  /rates/{code}:
    parameters:
      - name: code
        in: path
        required: true
        schema:
          type: string
    get:
      summary: Rate for a currency
      responses:
        '200':
          description: Known code
  • openapi is the OAS version. info.version is the document.
  • A Path Item lists allowed methods. Omitted methods are not documented operations.
  • Path templates need a required: true path parameter of the same name.
  • Building openapiOf does not bind a port. Twin: docs/capstone/quotes.openapi.yaml.

Layers

  • Core — rateOf / convertAmount. No HTTP, JDBC, env, logs, metrics.
  • Http — status, JSON, logs, counters. No catalog Map.get.
  • Persistence — Flyway and transact. Named here; wired in scala-031.
  • Runtime — Ciris, HEALTHCHECK, uid.
