Action pin

uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7
  • Forty lowercase hex characters. Not @v7, not a short SHA, not @main.
  • The comment is the tag you resolved. Dependabot can still open a PR.
  • Annotated tag: pin the commit, not the tag object’s own SHA.
  • pinPipeline rewrites Day 26 uses:. Tests compare ci/quotes-pinned.yml; they need not wait for GitHub. Live ci.yml stays the Day 26 contract.

Image user

RUN adduser -D -H -u 1000 app
USER 1000
CMD ["java", "-jar", "quotes.jar"]
  • No USER means root (uid 0). adduser needs root, so it comes first.
  • Exec-form CMD still makes java PID 1. The uid is 1000.
  • hardenedDockerfileOf renders the twin. packaging/quotes/Dockerfile stays Day 25.

Do

  • Reuse the resolved ActionPin values. Do not invent SHAs.
  • Keep contents: read. Keep rateOf as Map.get.
  • Pass tokens through process env / Ciris Secret, not ENV / COPY .env.

Do not

  • uses: …@v7 as the pin. Tag-object SHA for an annotated tag.
  • USER 0. Debian useradd on this Alpine base.
  • Bake token / password / Secret / .env into a layer.
  • Change Day 25 / Day 26 contract files to make this unit pass.
  • Introduce CodeQL, Scorecards, sha_pinning_required, capabilities, or distroless. Health checks are scala-028.
