PostgreSQL repository layer

Transact at the rim. Inject the Transactor. Hikari is a Resource. Tests use H2.

Lesson: PostgreSQL repository layer. Docs: Connecting, Managing Connections. This repo pins org.typelevel doobie-core / doobie-postgres / doobie-hikari / doobie-h2 1.0.0-RC13. Package: org.typelevel.doobie.

Session

findRate(code).option              // ConnectionIO — no JDBC yet
findRate(code).option.transact(xa) // IO — one transaction, then close
  • Compose with for before transact to share one session.
  • Two transact calls are two sessions.

Repository

final class RateRepository(xa: Transactor[IO]):
  def find(code: String): IO[Option[RateRow]] =
    findRate(code).option.transact(xa)
  • Inject xa like DeskConfig. Do not hide it inside rateOf.
  • .option for zero-or-one. .unique fails if the row is missing.

Production versus tests

postgresHikariConfig(url, user, password)  // fields only; no connect
HikariTransactor.fromHikariConfig[IO](cfg) // Resource of a pool

Transactor.fromDriverManager[IO](
  driver = "org.h2.Driver",
  url = s"jdbc:h2:mem:$name;DB_CLOSE_DELAY=-1",
  user = "sa",
  password = "",
  logHandler = None
)
  • Postgres driver class: org.postgresql.Driver. URL is an injected value.
  • Without DB_CLOSE_DELAY=-1, H2 mem dies when transact closes.
  • Unique mem name per test.

Do

  • Keep rateOf as the pure Map lookup this unit.
  • Transact Day 21’s Query0 / Update0 — do not concatenate.
  • Assert production config without calling postgresPool.use.

Do not

  • Put transact or a JDBC URL inside rateOf / convertAmount.
  • Use DriverManager against Postgres as the production pool.
  • Call postgresPool.use without a live Postgres (that is scala-024).
  • Introduce Flyway, Testcontainers, H2Transactor, pgtypes, LISTEN, or custom Strategy in this unit — Flyway is scala-023.
