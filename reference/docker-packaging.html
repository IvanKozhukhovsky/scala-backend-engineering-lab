Docker and reproducible runtime packaging

Image is the package. Container is the process. Dockerfile is the recipe: pinned JRE, JAR, ENV, exec-form CMD.

Lesson: Docker and reproducible runtime packaging. Docs: image, container, Dockerfile, Scala CLI package. Base pin: eclipse-temurin:21-jre-alpine-3.24 (eclipse-temurin).

Layers

  • Dockerfile — text recipe. Not a running process.
  • Image — immutable package (quotes:0.1.0). Not latest.
  • Container — isolated process from that image (docker run).
  • postgres:16-alpine — Day 24’s database process. Different image.

Recipe

FROM eclipse-temurin:21-jre-alpine-3.24
WORKDIR /app
COPY quotes.jar quotes.jar
ENV QUOTES_CODE=EUR
CMD ["java", "-jar", "quotes.jar"]
  • ENV persists; docker run --env KEY=value overrides. Ciris reads process env.
  • Exec-form CMD is a JSON array. It does not run at build time. java is PID 1.
  • dockerfileOf(runtime) renders the same text. Tests compare; they need not docker build.

Build on the host

scala-cli --power package . --assembly --preamble=false \
  -o packaging/quotes/quotes.jar --main-class day25.Day25
docker build -t quotes:0.1.0 packaging/quotes
docker run --rm --env QUOTES_CODE=GBP quotes:0.1.0
  • --power is required for package.
  • --preamble=false so java -jar works without a bash header.
  • One-liner: --docker --docker-from eclipse-temurin:21-jre-alpine-3.24 --docker-image-repository quotes (default tag latest — prefer an explicit --docker-image-tag).

Do

  • Pin JVM 21 JRE. Keep rateOf as Map.get. Pass PackConfig in.
  • COPY only the assembly. Config via ENV / --env.
  • Keep Postgres in its own image when you need a catalog.

Do not

  • FROM postgres for the service. COPY . .. Install Scala CLI in the runtime.
  • Bake tokens or .env files into layers. Use latest as the app tag.
  • Put Docker or env lookups inside rateOf.
  • Introduce Compose, jlink, GraalVM, USER, health checks, or CI image publishing (later units).
