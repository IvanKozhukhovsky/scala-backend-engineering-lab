Service architecture, config and logs

Load once. Pass values. Log maps at the rim. Keep the core pure.

Lesson: Service architecture, configuration and structured logging. Docs: Ciris Configurations, log4cats README. This repo pins ciris 3.15.0 and log4cats-core 2.7.1.

Wiring

  serviceName: String,

  : Either[ConvertError, ConvertOut]

def convertRoutes(
  config: QuoteConfig,

  • IOApp (or the test) loads config and holds the logger.
  • The core takes Int / String, not env names.
  • Secret.toString is a short SHA-1 prefix; .value unwraps.

Do

  • Fail at startup if required config is missing.
  • Keep 400 / 422 / 404 / 405 from scala-018.

Do not

  • Call sys.env or logger.info inside convertAmount.
  • Put Secret.value in a log ctx or a JSON body.
  • Introduce Ember, slf4j/logback, http4s Logger middleware, metrics, or tracing in this unit.
