# Start the next learning unit

Read `MISSION.md`, `curriculum.json`, `NOTES.md`, and `learning-records/`. Identify the earliest curriculum unit whose `verificationStatus` is not `verified`. If an earlier exercise is awaiting verification, do not start new material; guide the learner through verification first. Otherwise use the installed `teach` skill to teach the next tightly scoped concept, then give an independent exercise without providing its full solution. Do not mark mastery without evidence.
