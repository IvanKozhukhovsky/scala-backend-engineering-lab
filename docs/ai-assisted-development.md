# AI-Assisted Development Policy

AI is used in this repository as an engineering tool, not as evidence of competence by itself.

## AI may

- Teach a concept using trusted primary sources.
- Ask retrieval questions and design practice exercises.
- Explain compiler/test failures after the learner has attempted the problem.
- Review code independently and identify correctness or maintainability issues.
- Help create deterministic tests, CI, documentation, and repository tooling when their purpose is understood.

## AI should not

- Silently write the learner's independent exercise before an attempt exists.
- Mark a curriculum unit mastered from generated code alone.
- Introduce advanced frameworks solely to make the repository appear sophisticated.
- Present unverified ecosystem/version claims as fact.
- Rewrite learner code gratuitously after it already satisfies the intended behavior.

## Evidence of authorship and learning

The meaningful portfolio evidence is the progression visible in commits, independent exercise files, tests, learning records, review corrections, architectural decisions, and the final capstone. The repository therefore records both implementation and verification rather than hiding AI usage.
