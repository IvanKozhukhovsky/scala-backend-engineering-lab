Http asks; Persistence answers

The architecture note already split the jobs. Core still decides InvalidQty / UnknownCode from values. Persistence still runs Flyway then findRate(code).option.transact(xa). Http still maps status and JSON. The missing wire is a function Http can call without seeing Transactor.1

doobie Connecting: transact is ConnectionIO ~> IO — “connect to the database and execute single transaction.” Day 22 already put that inside a repository. This unit passes String => IO[Option[Int]] into routes.

convertAmount therefore takes the Option[Int] the lookup returned. It does not call rateOf. rateOf stays the seed oracle (EUR → 108) so you still know what Flyway + seedRates should store. Fast contract tests inject a memory lookup. One H2 suite migrates, seeds, and runs HttpApp. One Testcontainers GET proves the same path on Postgres — Day 24’s Resource, not a new Docker skill.

Failed session is not a miss

Cats Effect: attempt materializes a sequenced exception into Either[Throwable, A] — the inverse of raiseError.2 Three results, three statuses:

Cats Effect IO error handling. Pin remains cats-effect 3.6.4. Do not start handleErrorWith retry loops or munit-cats-effect in this unit.

RFC 9110: 503 means the server is currently unable to handle the request, likely after some delay; it MAY send Retry-After. 500 is an unexpected condition inside this process.3 A failed JDBC session is unavailable catalog, not a surprise bug in convertAmount. Map Left(_) to ServiceUnavailable(ApiError("unavailable")). OpenAPI stays silent — same move as 405 in Day 30. ADR 3 records it.

RFC 9110 §15.6.4 and §15.6.1. This unit does not require Retry-After. Unhandled exceptions at the Ember edge become 500 with a swallowed body — http4s error handling — so map the failed lookup yourself before the task fails. 
lookup(code).attempt.flatMap {
  case Left(_)            => ServiceUnavailable(ApiError("unavailable"))
  case Right(None)        => NotFound(ApiError("not_found"))
  case Right(Some(cents)) => Ok(RateOut(code, cents))
}

Liveness does not transact

Day 28: GET /health answers whether the process can respond. A counter lives on /metrics. If health transacts, a downed catalog looks like a dead JVM. Inject unavailableLookup: health stays 200 HealthOut; GET /rates/EUR is 503. Production hardening, docs, and release wait for scala-032.

Primary source Read RFC 9110 503 (currently unable; MAY Retry-After) and skim 500 (unexpected condition). Read Cats Effect IO through attempt. Skim doobie Connecting for transact as one session. Skim http4s Error Handling — a failed task at the backend is 500 unless you map it. Stop before Tapir, codegen, Retry-After as a required header, circuit breakers, jdbc:tc:, Flyway clean, and putting 503 into the Day 29 YAML.
