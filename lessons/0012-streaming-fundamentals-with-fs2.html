A stream is a lazy description

Stream[F, A] is a sequence of A values produced by an effect F — often Pure for pure steps or IO for Cats Effect.1 Like IO, constructing a stream does not run it. You build a pipeline; something at the rim must compile it to pull elements through.

FS2 guide (see primary source): streams are “pull-based” — consumers request the next chunk; producers do not dump an entire collection up front. 
import fs2.Stream

Stream.emit(1)              // one element
Stream(1, 2, 3)             // finite literals
Stream.emits(List("a", "b")) // from a collection

Pure transforms — map, filter, take — stay inside the description. They fuse into the pipeline without running effects. Concatenate with ++ when you need “this stream, then that stream.”

Pure steps vs effectful steps

When a step needs an effect — DB lookup, HTTP call, logging — use evalMap (transform each element) or evalTap (run an effect, keep the element). Each callback returns an IO[...]; FS2 sequences those effects as the stream runs.2

FS2 API: evalMap is the stream analogue of flatMap on IO — one effect per element, in order unless you opt into parallelism later. 
def rateStream(codes: Stream[Pure, String]): Stream[IO, Option[Int]] =
  codes.evalMap(code => IO(rateOf(code)))

Keep domain lookups pure (rateOf returns Option). Suspend them inside IO(...) in evalMap, the same way Day 14 wrapped lookupRate. Do not call unsafeRunSync inside evalMap.

Drop unwanted elements with filter / collect, or stop early with take. That is how you “skip unknown currency codes” without building an intermediate list first.

compile runs at the edge

compile turns the description into something executable in F.3 Common terminators:

FS2 guide: compile.toList collects, compile.drain runs for effects only, compile.fold aggregates — all return an IO when F = IO.
  • .compile.toList — materialize every element (fine for tests and small data).
  • .compile.drain — run effects, discard output (logging pipelines).
  • .compile.fold(0)(_ + _) — aggregate without storing the whole stream.
rateStream(codesFrom(List("EUR", "GBP", "JPY")))
  .evalTap(m => IO.println(s"rate=$m"))
  .compile
  .drain

Apps: keep compile.* in IOApp or tests — same edge rule as Day 14. This unit stays on in-memory streams; file I/O, sockets, and through pipes come later.
