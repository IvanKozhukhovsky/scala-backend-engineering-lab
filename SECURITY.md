# Security Policy

This is an educational repository, not a hosted production service. Do not commit real credentials, tokens, private keys, production connection strings, or personal data.

If a secret is committed accidentally, treat it as compromised: rotate/revoke it first, then remove it from Git history. Do not paste live secrets into AI chats, issue bodies, logs, or learning records.

For a vulnerability that contains no sensitive exploit data, a GitHub issue is acceptable. For sensitive disclosure, use GitHub private vulnerability reporting if it is enabled for the repository rather than posting the details publicly.
