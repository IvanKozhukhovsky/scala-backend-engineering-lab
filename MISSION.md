# Mission: Scala Backend Engineering

## Why
Build professional Scala skills for software engineering and backend development, with enough depth to design, implement, test, review, and operate production-oriented services rather than only solve syntax exercises.

## Success looks like
- Implement an idiomatic Scala 3 backend service with explicit domain modeling and error handling.
- Explain important design decisions without relying on AI-generated answers.
- Use automated tests, formatting, CI, code review, and basic DevSecOps practices as part of normal development.
- Work with HTTP APIs, PostgreSQL, concurrency/effects, configuration, logging, and observability.
- Maintain a public GitHub repository that provides verifiable evidence of learning and engineering progress.

## Constraints
- Learning must be incremental: lesson, retrieval, independent exercise, verification, then the next lesson.
- AI acts primarily as tutor, reviewer, and debugger; it must not silently replace independent practice.
- Stable fundamentals are preferred over chasing every new library release.
- Public documentation is written in English; tutoring discussions may be in Russian.

## Out of scope
- Frontend development inside this repository.
- Production cloud deployment before the backend and testing foundations are complete.
- Premature framework specialization before core Scala and functional-programming concepts are understood.
